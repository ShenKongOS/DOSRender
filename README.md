# DOSRender
# 介绍
It can render fragment shader for DOS.
这是一个为DOS系统设计的光追渲染器。支持24/32位真彩色。大部分实现逻辑，像`vec2/vec3/vec4`，和相关GLSL函数等模拟以及DOS系统渲染切换在`sk.hpp`中。
`sk.hpp`保留了256色的调色板渲染模式，但不建议使用。真彩色模式下程序终止运行后，系统会崩溃，还未排查出原因，初步猜测是DOS系统栈管理不太适合这种较大内存占用的程序运行。
`s1.cpp`中包含了渲染器的主要循环逻辑。

## 运行
你可以直接运行`example`中编译好的程序，同时，里头包含了相关代码。
